# 公共充电验收口径

桐驿公共充电运维组接收安装方调试台账，各站需独立核对站号和枪口检测资料，再交接送电调度。手工登记时，重复枪口常在后续巡视才发现，错站需要逐条撤销，同一批多个现场的移交时间被绑定。

08:30 收到 TY-1124-站批，08:35 核对四个站号，08:40 录入枪口序列和检测值，08:45 设定演练下限 1000 kΩ，08:50 后台逐站入表，08:52 核对两个通过站与两次搁置，09:05 导出交班单。

使用 PostgreSQL 主键检测重复，保存点覆盖站表与所有枪口写入，有质量失败也回滚。同批剩余通过站可以使用已回滚站曾尝试写入的枪口编号。默认通过 TY-S11、TY-S14，登记 3 个枪口。绝缘下限为模拟调试参数，整批使用数据库暂存表与最终结果快照，供验收培训。

## 校准撤销与送电核对

- 送检登记枪口时同时记下仪表号和检测时间；每个枪口读数都写入 `port_tests` 台账，即使所属站被保存点回滚也保留，撤销单迟到时仍能追查到原检测记录。
- 计量室撤销单按「仪表号 + 失效时段」登记在 `revocations`。判定时逐条比对：同仪表、检测时间落在失效时段内即为失效读数。
- 分站结论：含失效读数且尚未复测合格的通过站判「停送」；涉及枪口全部在撤销登记之后、失效时段之外复测合格则「恢复送电」；未涉及的通过站照常「放行」，原搁置站维持「搁置」。
- 撤销单登记与核对单签核共用 `clearance_guard` 单行 `FOR UPDATE` 锁，并在锁内重新读取台账，并发登记的失效读数不会被放行。
- 签核按站记录判定：有可放行站点即可签署，停送站随单记录为不放行；全部通过站点均停送，或批次没有检测台账时拒绝签署。
- 签核时的判定与依据写入 `reviews.snapshot` 并存 SHA-256；之后到达的撤销单只影响实时核对视图，不覆盖已签核对单。
